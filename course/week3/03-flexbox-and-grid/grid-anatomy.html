Every demo below is the same 3-column × 2-row grid (grid-template-columns: repeat(3, 1fr), grid-template-rows: repeat(2, 56px)). Only the highlight changes — so you can point at each word from section 4a.

① Grid lines — the numbered dividers

3 columns are framed by 4 vertical grid lines (badges below). N tracks ⇒ N + 1 lines. You place items by line number: grid-column: 1 / 3 = "span from line 1 to line 3."
